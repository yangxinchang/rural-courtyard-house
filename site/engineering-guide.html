2. 结构安全与关键专项深化红线

红线 01中庭 8.40 × 7.80m 挑空玻璃顶

  • 玻璃仅封二层东西连廊之间挑空口，西低东高找坡（+3.74m → +3.98m），不覆盖两侧连廊与前屋露台；东侧高位雨廊单独保留。
  • 严禁把护栏计入承重，严禁将「中央无柱」视为已验算结论：须由结构专业按实测跨距、两侧连廊边梁与柱位核算钢/铝主次梁截面、抗风揭、挠度及连接节点。
  • 顶面必须选用夹胶中空 Low-E 安全玻璃（禁止单片钢化），周边保留护栏并设置「不可踩踏」永久标识。

红线 02东西院墙补高与东套卫外扩

  • 东西两侧院墙补高至 +3.420m 与二层连廊板底相接形成整面实墙，取消旧中部压顶；顶部拉结、抗侧移与防水收口须做专项结构节点，不可直接砌筑无拉结高墙。
  • 两层东侧外扩套卫（每层外包投影约 7.41㎡）须核实可建红线，并与主楼框架拉结设计独立基础/梁板及外墙保温防水。

红线 03前屋露台与电动晾衣亭荷载

  • 前屋平屋顶为上人娱乐晾晒露台，铺装必须采用轻量室外防滑系统（300×300 / 300×600mm），严禁把院子厚石材与厚砂浆垫层直接搬上楼顶。
  • 西侧晾衣亭电动升降晾衣机支架须可靠锚固于亭梁（禁止挂在薄屋面饰板上），按所选机型核定静/动荷载、抗风摆动及室外防雨等级。

红线 04临街厚重大门与落地玻璃推拉门

  • 临街 2400mm 双开厚门（110mm 门扇意向）选用耐候金属门体配木纹饰面（防腐钢/铝合金/铸铝），室内木门不得直接当室外门；提前预埋重型铰链与门柱加强件。
  • 后楼首层朝院双轨横拉玻璃门须核定安全玻璃、重型滑轮承载、轨道外排水与低门槛防倒灌节点，不以「无门槛」牺牲挡水能力。

3. 给排水、防水防潮与暖通排烟要点

雨污分流与中庭玻璃顶排水（图册 A-107 / P-102）

  • 中庭主排 + 独立溢流：玻璃顶向西槽收水，西槽两端向北段低点（X1.875, Y13.95）找坡，主排水管沿西廊板下向外降坡接西侧雨水干管；槽内另设独立溢流口与溢流管，不与主立管共用。
  • 二楼冲洗与防回流：露台水池柜东侧预留水枪快接口、可检修关断阀及防回流装置；雨水系统严禁接入洗衣废水或含清洁剂污水。
  • 冷凝水与渗漏：玻璃顶与外墙、露台、西槽交接处须补泛水收边及玻璃内侧冷凝水接排槽，防止冬夏季滴水至首层。
  • 屋后排污：西/东湿区与二楼过厅洗衣机排水（均带防臭存水弯与立管清扫口/通气帽）统一排至屋后检查井 IW1～IW3 及化粪池；二楼板下横管 1.5% 坡度须结合吊顶净高逐点复核无反升。

农村自建房防水防潮与双路热水

  • 首层必做防潮层：首层全部房间（尤其老人房、堂屋、起居室）地面垫层下满铺 SBS / PE 防潮膜，内墙脚 1.2m 内刷抗碱防潮底漆，防止梅雨季地面返潮、墙皮起碱脱落。
  • 厨卫闭水与节点：管根、地漏、门口止水坎、窗台外坡及淋浴区先做满涂防水并闭水验收，美缝与防霉胶不替代防水系统。
  • 前厨 / 后楼双路热水：前屋厨房与后楼湿区跨院相隔，建议前屋厨房设独立小厨宝或独立燃气支路，后楼设集中热水器 + 回水管（零冷水），首层热源接口位于家务前室东侧实墙（避开北窗）。

厨房双猛火灶独立排烟（图册 25）

  • 烟机顶部沿东墙穿墙上翻，室外独立立管位于 X11.80 / Y1.60，示意终端标高 +6.10m，意向管径 Φ180mm，总路径约 4.88m，设防雨帽、止逆阀及室外检修口。
  • 排放点远离前屋露台休闲与晾衣区，独立排放，严禁并入卫浴排风或污水通气管；双灶同开时须核实烟机风压、止逆防倒灌及自然补风路径。

空调内机避吹与中庭夏季散热

  • 老人房空调（AC-3）已移至东墙南段梳妆台上方，避开床头直吹；全部 6 台空调（AC-1～AC-6）外机集中西侧设备区，冷凝水独立有组织排放。
  • 中庭防晒散热：玻璃顶下方设夏季电动折叠遮阳天幕 + 东侧高边电动排热天窗；实际落地建议优先评估外遮阳（隔热效率显著高于内遮阳），并在低处预留可开启防蚊百叶进风口形成自然拔风。

4. 电气、弱电与 29 组回路总表

配电分区与强电新增预留

  • 三级分箱：DB0（前屋）、DB1（后楼首层）、DB2（二层家庭厅东墙完整墙段）。插座与设备回路按 30mA 剩余电流保护设计意向，PE 导体全程连续。
  • 必留独立/专用点位：二楼过厅洗烘一体机（DB2-W1）、亭内电动晾衣机（DB0-D1）、中庭电动遮阳天幕与东侧电动排热天窗、卫浴电热毛巾架、堂屋备餐柜轨道插座、中庭台阶 IP65 防水感应灯带、大门及室外安防监控。
  • 烤箱与洗碗机插座设在邻柜可开启检修位，禁止封死在设备背面；全屋具体线径、断路器与进线负荷须按最终电器功率校核。

跨栋全屋弱电与智能布线

  • 前屋 + 中庭 + 后楼两层跨度大、砖混/框架墙体厚，普通单路由器信号极易衰减。
  • 建议弱电箱统一预埋超六类（Cat6A）网线至：前屋通堂/客房、后楼首层起居室、堂屋、老人房、二层家庭厅、主卧、次卧，采用 AC+AP 吸顶/面板或有线 Mesh 实现全屋及院落无缝漫游。
  • 老人房床头配双控一键总关 + 墙脚/套卫门外/台盆下低位感应起夜导向灯。

5. 精装构造、适老细节与选材落地（2026-11-20 最新）

地面与墙顶构造

  • 后排卧室与公区统一石纹砖：浅灰米哑光/柔光石纹砖（600×1200 / 600×600mm）通铺，取消通堂与堂屋黑色波导线，用同色环氧彩砂美缝；仅前屋客房留浅橡木纹砖或防潮多层实木。
  • 吊顶化繁为简建议：公区可用极简双眼皮石膏板边吊替代复杂深灯槽，卧室单边双眼皮 + 窗帘盒，降本且杜绝积灰藏虫。
  • 中庭与入户台阶：踏步前缘嵌深色金属防滑条，后楼门廊台阶底面暗藏 IP65 防水暖光感应灯带。

厨卫与定制柜体收口

  • 厨房防油升级：墙砖通铺到吊顶（避开北窗）；冰箱上方补同色顶柜收口并留散热缝；北墙改三门封闭浅橡木吊柜 + 柜下感应灯带；地柜优先隐形免拉手。
  • 卫浴墙砖通铺到顶：四套卫浴均取消 1.32m 半高墙裙，墙砖绕窗满贴至吊顶防受潮起皮；升级四杆电热毛巾架；配储物镜柜与淋浴防磕碰嵌入式壁龛。
  • 全屋衣柜与高柜到顶：三间五列衣柜、家庭厅共享高柜、客房衣柜与食品高柜顶部加同色封板贴齐 2.88m 吊顶底，消除积灰死角。

起居、适老与窗帘门厅

  • 客厅与家庭厅：电视背景墙及木格栅通顶落地，电视柜改离地 200mm 悬空壁挂 + 底灯（扫地机器人可进出）；家庭厅双人书桌向东延伸衔接共享高柜。
  • 老人房与套卫适老：老人房床头精简掉台灯（用阅读壁灯 + 起夜灯带）；取消散铺地毯防绊倒；淋浴区微坡无高差 + 长条地漏；坐便侧墙预埋实木基层备装上翻扶手（坐便中心距墙/柜 ≥400mm）。
  • 窗帘与门厅：主卧西窗改内嵌全遮光蜂巢帘（或罗马帘）；次卧北窗齐窗台短帘；避雨门厅挂衣钩移至东窗北侧加浅橡木防污背板，双鞋格配可取出接水托盘。
