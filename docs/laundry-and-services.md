# 二楼洗衣、电动晾衣及全屋水电深化

2026-11-07。根据蓝框，二楼洗烘一体机从亭子移至后楼主卧前公共过厅西段；亭内改为电动升降晾衣区，右侧旧落地架取消。三间卧室同步五列衣柜。

## 二楼洗衣机

- 720宽×780深凹位，机器暂按600宽×650深×850高mm，朝南。北墙局部向主卧退330mm，主卧南窗从2050收至1800mm，右窗帘随移。机器前方1000mm为通行／操作带，开门与走人分时。
- 原机位改收纳，亭子北侧水池保留。后楼机位台面约940mm高、抗振垫，背后约90mm暂留软管和检修；水阀与插座在上方两侧，服务面板可拆。真实机型的机深、凸门、散热与开门半径仍须核实。
- DB2-W1从二楼分箱供电，洗衣机独立回路；供水走西外墙与过厅吊顶，到左侧可达关断阀。排水口距本层地约650mm，最终按机型安装说明。
- 地漏和机器排水分别带可维护防臭节点，接西外墙新增污废水立管，含清扫与屋面通气；再沿西侧接污废水检查井。雨水独立，不接洗衣废水。防水与排水坡向需要结合真实地面做法。

## 亭内电动升降晾衣

核定状态：所在地、施工状态及型号均未定。空间复核完成，承重、锚固及室外适用性尚未核定；见[核定记录](drying-verification.md)。

- 原亭子中的桌椅和右侧落地晾衣架取消，亭子北侧水池与收纳保留。晾衣投影约1400×2300mm，在四根亭柱内，中间及东侧露台留空。
- 晾衣杆升起距露台完成面约2250mm，降下约1250mm，升降行程1000mm；三条晾衣杆及下挂被褥杆，钢索随下降伸长。3D提供升起、降下和定位按钮，恢复整屋回到升起状态。
- 电机、集成灯、梁间安装支架及四点吊索均有实体示意。新增独立DB0-D1回路，线路沿前屋檐口、亭梁和亭柱防护敷设；东后柱设约1300mm高带停止墙控，避开水池。
- 支架连接亭梁，不能把设备直接挂在薄屋面饰板上。实际承重、抗风、行程、遇阻保护、防雨等级和断电操作须按所选机型与亭子结构校核；本次不指定品牌及承载公斤数。

## 全屋水电复核

- DB0前屋、DB1后楼首层、DB2二楼；DB2移到家庭厅东墙完整墙段。入口开关补齐，侧主门开关避开门洞，厨房和卧室插座避开电器中心、衣柜及窗；烤箱、洗碗机的邻柜内插座明确保留可开检修条件。
- 照明、普通插座与设备回路分组；厨房、洗烘、空调等设备分别预留专线。插座／设备回路采用30mA剩余电流保护的设计意向，PE保护导体连续。没有实际功率和供电资料，线径、断路器、进线容量与分相未定型。
- 四套卫浴增加淋浴和干区地漏。二楼排水改至楼板下可检修路径，1.5%仅作为本轮空间预留，真实坡度、管径和吊顶净高待核；逐点沿管路到化粪池入口检查无反升，包括立管接入处。
- 首层热源接口移到家务前室东侧实墙，避开北窗。冷、热、水电及雨污各自表达；热源类型、容量、保温和循环尚未选定。
