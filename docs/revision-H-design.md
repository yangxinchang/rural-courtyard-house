# H版：避雨入户与居住布局优化

日期：2026-11-05。依据用户本轮三张截图：复核首、二层房屋布局及装修，并将红框楼梯南入口前的露天区域做起来避雨。沿用坐北朝南、六人常住、前房平露台、后楼红瓦阁楼、双连廊、右后封闭梯、最后二层侧门、完整堂屋和屋后5米；实测面宽、所在地和市政条件仍待补。

## 避雨门厅

- 先按红框范围在原梯间南侧增加一层避雨门厅，外包X11.40～14.34、Y14.40～16.50，约2.94×2.10米。原梯段、两平台、二层主门不移动。
- 门厅完成面+0.300，与后楼门廊及梯间首层平台连续；从西侧门廊的900毫米门进入，向北穿原1100毫米梯间门上楼。西门设在Y14.64～15.54，与门廊相接。原露天梯门前150毫米踏步改为室内平接，不保留室内凸起。
- 南、东侧有墙及采光窗，西侧接门廊；顶部完整覆盖，与原梯间南墙和后楼二层板边衔接。顶面控制标高+3.600，为非上人遮雨屋面意向，不延伸为露台。
- 地面为耐水防滑砖意向，东窗下设换鞋凳；西门至北侧楼梯门留连续通路。门厅不占堂屋，不把首层进入楼梯的路线放进卧室。
- 增加屋面雨水口及独立雨水管联系，外围冷热水／厨房排水南侧绕行段移至Y14.05，避开新增门厅投影。仅表达排水方向；找坡、泛水、门窗防雨、接缝、管径、固定及基础需施工深化。
- 用户随后补充并确认：红框门厅与**二层东侧连廊**均需加顶；首层院内通路不另建整段新顶棚，院子保持开敞。

以上轮廓是设计方对截图的定位，非实测用地或结构许可；新增封闭投影约6.17平方米，面积口径另记。

## 二层东侧雨廊

- 用户已明确加顶楼层为二层。保留原X10.20～11.40、Y6.60～14.40连廊和+3.600地坪，新增浅色轻型顶棚，外轮廓X10.10～11.50、Y6.40～14.64，覆盖前露台到后楼东侧小门的整段通路。
- 顶棚控制面最高+6.600，向东侧示意下降40毫米；板面、细框架、原栏杆线上的细柱和三处照明均入模。示意梁下净高约2.78米，柱的视觉宽度不超过原扶手包络；构件不是施工截面。
- 东侧设收水槽及雨水管，接独立雨水干管，避免向步行面直接滴水。屋面搭接、接墙泛水、防水、侧向飘雨和抗风、支撑连接均需深化。西侧连廊维持原样。
- 整屋显示新顶棚，首、二层布局隐藏高处顶棚，便于查看通路；新增“查看东侧雨廊”聚焦完整外观。

## 居住布局与装修

- 老人房床旋转90度，床头朝西，布置包络X0.98～3.13、Y17.20～18.84，保留1.50米床垫。主卧同样床头朝西，包络X0.98～3.13、Y17.20～19.14，保留1.80米床垫。保留两房Y17.02～18.82、窗台高850毫米的原西窗：床头实体顶高750毫米，西墙低背景顶高720毫米，均低于窗台；阅读灯放窗两侧实墙带，西窗补两侧帘片。床头柜置西侧两端，避开北侧套卫门扇。
- 卧室北侧连续通道保留；床尾至东侧墙内面约950毫米，以共用坐标和实体复核，门扇、窗帘及实际家具安装条件不混为已验收。
- 家庭厅沙发、500毫米沙发前净距及南部入户通路保留。原东侧中段高柜移至东墙北端X7.06～7.66、Y21.55～23.15，柜长及高度保留；双人书桌缩至X4.40～6.65，座椅位置相应向西调整，避免高柜挡住电视和挤占书桌进出。
- 家庭厅AC-6内机沿原东墙南移至Y20.80，避免与北移高柜顶端重叠；冷媒、冷凝水及电源端点随共用数据同步，实际安装和送风继续按机型深化。
- 双床房两张0.90米床及独立入户过道保留。床下由侧拉抽屉改为上掀式床箱意向，关闭状态的面板及拉手均收在家具布置包络内，不再侵占床侧700毫米间距。上掀开启、气撑和承载需按实际产品复核，模型不宣称已做机械设计。
- 首层公卫前室、洗衣机和家务柜保留G版独立动线；堂屋不加固定家具。起居室补与米白／木色协调的沙发背景，卧室补床头阅读灯意向，门厅补换鞋凳和照明。
- 所有家具、装修和新门厅从同一份Python数据生成平面、GLB及离线说明。新的屋顶独立分组，首层布局自动隐藏；整屋“显示屋顶”关闭时隐藏，二层可看门厅顶面的位置。
