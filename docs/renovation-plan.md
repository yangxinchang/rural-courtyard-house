# 装修图纸与交互三维实施清单

> 使用 writing-plans 制定步骤，随后在当前项目逐项执行和验证。用户已要求“列出待做事项，并逐步完成”。项目不是 Git 仓库；本轮不提交或上传文件，测试仅在 tmp 中本地保留。

**目标：** 先完善楼梯、卧室、厨房、卫生间的装修布置图，再把同一套布局和材质落实到能直接打开、旋转和查看室内的三维页面。

**架构：** 沿用现有 Python 共用尺寸、Matplotlib 图纸及 Blender 模型。增加一份共用家具与洁具数据，供二维和三维共同读取；Blender 导出 GLB，浏览器用本地 Three.js 加载嵌入的数据，双击页面也可工作。

**技术：** Python 3、Matplotlib、Blender 4.2.3、Three.js 0.170.0；无运行时网络资源，无需账户或云端服务。

**设计依据：** docs/design-brief.md，及本次用户要求。地块继续暂按 12 × 24 m，朝南；装修已确认沿用米白墙、木色家具、青绿色琉璃瓦。

## 全局约束

- 先更新和输出装修图纸，再生成对应三维模型。
- 全部内容留在本项目文件夹。
- 后楼三开间两层加半层隔热阁楼，中院，前房三开间一层。

## 重点复核

- 双击 file:// 打开时模型可见，离线也能加载。
- 无 WebGL 时明确显示原因，不无限停留在加载界面。
- 从首层或二层返回整屋时恢复屋顶、阁楼和所有楼层。
- 进入房间时切到正确楼层，俯视与室内视角可相互切换。
- 家具不侵占楼梯前平台；门扇、厨房工作区、淋浴和洁具位置在图模中相同。

## 具体设计决定

- 厨房改为西侧与南侧 L 形台面，西侧依次设置灶台、备餐台、水槽，冰箱在东南；餐桌在北部，入院门移向东北，保留东侧通道。
- J版首层西公卫从东侧家务前室内开门进入，东老人套卫从卧室南门进入；二层套卫入口沿用。四处湿区的洗手台靠门侧、坐便器靠侧墙、后部横向淋浴区，淋浴分隔用移门概念。
- 楼梯前借用堂屋 1.05 m 深厅区作为前平台；原堂屋桌移除，只留侧面玄关柜。楼梯仍为 20 × 165 mm，踏面 270 mm，梯段 1050 mm，中间平台 1050 mm。
- 阳台和平台栏杆按约 1.10 m 高表达，竖杆间距缩小；实际防护与施工节点另行复核。
- 卧室用木地板、床头与滑门柜；厨卫用地砖，卫浴设镜柜和淋浴分隔。灯具位置与配色用于装修意向，不替代电气施工图。
