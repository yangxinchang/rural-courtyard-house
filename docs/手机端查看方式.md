# 手机端怎么看最方便

2026-11-09。按“省事程度”从高到低给三种方式，均基于当前浅色精装版（13张图、交互3D、GLB同版）。

## 方式一：微信直接发图（最省事，不依赖网络环境）

- 单张总览：[00-精装总览.jpg](../精装效果图/00-精装总览.jpg)，一张图看全13个视角。
- 15张手机图打包：[院居-浅色精装-手机图片.zip](../delivery/院居-浅色精装-手机图片.zip)（2.4MB，1600px长边，含总览与前后对比）。
- 直接把这15张图发微信/相册即可；对方点开就能放大看，不需要装软件、不需要联网加载模型。
- 缺点：不能旋转、不能进房间、不能开关门窗。

## 方式二：同一 Wi-Fi，扫码看交互3D（现在就能用）

电脑和手机连同一个 Wi-Fi：

1. 电脑保持开机，项目里的手机站点已在本机 `8088` 端口提供：
   [delivery/手机查看站点-O](../delivery/手机查看站点-O/index.html)。
2. 手机扫这张二维码：[手机查看二维码-局域网.png](../delivery/手机查看二维码-局域网.png)，三个地址任选一个能打开的：
   - Wi-Fi：`http://10.0.24.215:8088/3d.html`
   - 有线／路由：`http://192.168.1.123:8088/3d.html`
   - 备用：`http://192.168.0.203:8088/3d.html`
3. 打开后点“打开交互3D”，首屏约19MiB，建议 Wi-Fi，加载完可旋转、双指缩放、进房间、开关门窗。

若电脑重启、换 Wi-Fi 或 IP 变了，重新启动并在手机上直接输入新地址：

```bash
cd '/home/xinchangyang/chance_software/rural-courtyard-house/delivery/手机查看站点-O'
python3 -m http.server 8088 --bind 0.0.0.0
```

电脑的局域网 IP 用 `ip -4 addr show scope global` 查（当前是 `10.0.24.215`），二维码可用同一地址重新生成。

注意：

- 手机不能填 `localhost` 或 `127.0.0.1`，那会指向手机自己。
- 只适合同一网络、临时看；电脑关机或离开这个 Wi-Fi 就打不开。
- 微信内置浏览器若提示无法运行3D，点右上角“在浏览器打开”。

## 方式三：单文件离线版（手机本地打开，不联网）

[院居-3D-单文件离线版.html](../delivery/院居-3D-单文件离线版.html) 把模型、贴图、查看器全部内嵌在一个 26.1MiB 的 HTML 里，不依赖服务器和网络。

- **Android**：把文件传到手机（微信“文件传输助手”或数据线），在“文件管理”里点开，选择 Chrome／系统浏览器；首次加载约5～15秒，之后可离线旋转、进房间。
- **iPhone／iPad**：Safari 不能直接打开本地 HTML 的脚本，系统“文件”预览也不执行3D。可装支持本地网页的 App（如 Documents by Readdle 的内置浏览器），或在手机上用本地服务器 App 指向文件夹后开 `127.0.0.1`；否则用方式二或方式四更省事。
- 单文件只含交互3D，不含效果图库和PDF；图片仍用方式一的图包。

## 方式四：上传成 HTTPS 网站（长期、异地都能看）

把[手机查看站点-O](../delivery/手机查看站点-O)里的**全部内容**（`index.html`、`3d.html`、`model/`、`viewer/`、`精装效果图/`、`renders/`、`drawings/`、`docs/`）原样上传到任意静态托管，保持相对路径不变：

- 最省事：Netlify Drop、Cloudflare Pages 直接拖文件夹上传，几分钟得到一个 HTTPS 链接。
- 已有服务器/对象存储：传到网站目录或 COS/OSS 静态站点，入口设为 `index.html`。
- 微信里发这个 HTTPS 链接或它的二维码即可，异地、不同网络都能打开。

不需要数据库和后端；首次加载约19MiB，之后走浏览器缓存。图片为网页压缩版，打印或施工沟通用完整包里的2560×1440原图。

## 手机上的操作

- 单指拖动旋转，双指缩放/平移；竖屏控制区在模型下方，横屏在左侧。
- 选“整屋外观／首层／二层与露台／隔热阁楼”，再选房间可进“室内视角”。
- 点门窗可开关；侧栏可用“全部打开/关闭”“恢复整屋”。
- 打开“太阳与光影”可拖时间看窗影，这是示意日轨，未按所在地校准。
