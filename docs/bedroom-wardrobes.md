# 三卧室五列衣柜

2026-11-07，按用户三张蓝框图，老人房、主卧、次卧均改为五列、五扇门衣柜，约2000宽×550深×2400高mm。仍在原卧室各自连通的衣帽／书桌区；加长后的柜体沿墙布置，北窗横向让位，窗帘同步。

| 衣柜 | 位置 | 长衣杆距完成地面 |
|---|---|---|
| 老人房 | 首层北侧衣帽休闲区西墙 | 1550mm |
| 主卧 | 二层主卧衣帽区东墙 | 1850mm |
| 次卧 | 二层北侧书桌区西墙 | 1750mm |

每套由南至北五列：长衣、双层短衣、三抽屉与叠放、活动层板、被褥杂物；2080mm处设顶层板，顶部收纳被褥。板件、挂衣杆、衣架、层板、抽屉箱体和拉手均为实体模型。抽屉本轮不提供拉出交互。

五扇平开门分别可点击开关，单扇开启向外约400mm。侧栏“打开五扇门”可一起打开；“关闭柜门”原位关闭；“查看全部内部”暂时隐藏五扇门，独立查看全部分区。返回卧室可看实际柜位，卧室说明也可直达衣柜。恢复整屋关闭全部柜门。柜门打开会占用操作通道，开柜与走人分时使用。

三套柜体范围Y22.08～24.08。老人床北端Y21.44至柜体南端约640mm，600mm人体包络检查转弯通过。主卧北窗改为X2.90～3.40，东侧柜体不遮窗；两层东区北窗改X8.72～9.57，避开西侧高柜。窗帘和主卧衣帽区插座随之调整。
