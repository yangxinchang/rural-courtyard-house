# Q版：家具与装修细节深化（2026-11-07）

本轮按“优化当前设计的室内装修效果／做好家具和装修细节优化”执行。**房间布置、门窗、五列衣柜位置和P版水电均不改**，只把室内观感从概念体块推进到可读的精装效果，并把新增细节写进同一个Blender模型。

## 一、原状诊断

对比上一轮13张效果图，问题集中在五处：

1. **平**：墙面、顶面、地面几乎同亮度，缺踢脚、门窗套、分缝与材质起伏，房间像白色盒子。
2. **空**：床只有床垫和一条搭毯，没有床头、壁灯、地毯、挂画；客厅只有沙发茶几；餐边、门厅、卫浴缺生活器物。
3. **硬**：家具都是倒角方块，床品、靠垫、窗帘没有层次；床头板就是一块木方。
4. **暗角与过曝并存**：每个房间只有一个顶面面光加窗补光，家具背面死黑、白墙又发灰；窗上整幅纱帘挡住外景。
5. **镜头**：主卧、卫浴、避雨门厅的机位贴墙或正对门扇，画面一半是空墙。

## 二、材料与做法

全部在`scripts/interior_details.py`中以程序化节点实现，可随模型重建：

- 墙面：暖白灰泥加细凹凸与低频色差，消除大面积纯色。
- 木饰面：统一降低饱和度、轻微偏暖，补木纹凹凸和粗糙度变化；门、柜、家具不再发橙。
- 地面：石纹砖压暗约15%，粗糙度0.32～0.56起伏，保留细缝。
- 织物：亚麻/圈绒按贴图做织纹凹凸；地毯、床品、软包各自独立色阶。
- 玻璃：加透光度和菲涅尔反射，窗与淋浴隔断可读；纱帘减淡，不再挡窗。
- 灯具：亚麻灯罩带自发光，筒灯为深色环+发光片。

## 三、构造细节

- **踢脚**：干燥房间75mm深木色，湿区85mm同色瓷砖；自动在门洞处断开，不穿门套。
- **门窗套**：门洞两侧及上口70mm木色门套，双面生成，门扇开启后仍能读出洞口厚度。
- **顶面**：保留原叠级暗藏灯槽；按房间尺度加1～9个嵌入式筒灯，作为渲染光源与实际灯具示意。
- **床头**：低床头之上加浅橡木框＋亚麻软包床头（约1.16m高），老人房与次卧再加木格栅背墙与上下暗藏灯；主卧床头为西窗，不挂画。
- **窗**：保留原窗台、竖梃与分格；纱帘改薄，窗景可见。

## 九、浅色调整（同轮追加）

按最新意见把整体改为浅色精装，并处理两处具体问题：

- **二楼晾衣亭顶棚不再用黑色。** 顶板由深灰金属改为浅灰米色石涂金属，底面同色浅木吊顶，四柱由深色改为暖灰棕，梁改为浅橡木；顶面、檐口与柱从整屋和露台视角均不再是黑块。
- **后排不做木地板。** 老人房、主卧、次卧及后排卧室区的地面改为浅灰米石纹砖（600×1200示意，细缝），前屋客房保留浅橡木地面；图纸文字同步为“浅色石纹砖／米色织物”。
- **整体浅色。** 墙面提亮为暖白，室内门、柜体、踢脚与门窗套改浅橡木，家具台面与台盆保持暖白，窗帘、地毯与床品统一米色系；深色只留在电视、五金、窗框与室外门。
- **卧室加浅色背墙。** 老人房与次卧床头加木格栅背墙，上下藏灯；床头改亚麻软包＋浅橡木框，床尾加垂坠搭毯，减少纯白体块感。
