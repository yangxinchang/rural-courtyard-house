# K版：套卫外移、圆桌客厅与屋顶娱乐晾晒

日期：2026-11-05。依据用户连续标注：两层东侧套卫移到楼梯北侧红框空地，图2堂屋通往家务前室的门洞封闭，堂屋北段布置圆桌客厅；补齐厨房室外排烟路径、院墙连续连接，前屋屋顶作为室外娱乐及晾晒露台。沿用J版老人房／主卧2.2米床、客房／次卧1.8米床、后楼加深1米及屋后5米。

设计方安排两层东套卫叠合于X11.40～14.34、Y21.88～24.40，即梯间北侧、后墙齐平；共享梯间北墙封闭不留内窗，新增东／北采光窗及独立排风。套卫只从各自卧室北侧私用区进入，不通楼梯。原X9.30～11.40湿区并入各层北侧衣帽／书桌休闲区，拆除原内部隔墙；旧北窗改为普通采光窗。新湿区名义2.94×2.52米，参考净空约2.70×2.28米；新增楼板、外围梁柱、平屋顶及排水示意同步。西主卧套卫与首层西公卫沿用。

堂屋西墙北段门洞封闭，家务／公卫改经西起居室北门进入，不增设其他堂屋门。按新增“厨房不在里面吃饭”的理解，堂屋北段安排六人餐叙会客圆桌，直径1.20米、六椅围坐，包络放在北段，南侧活动及卧室入门空间保留；不再声称堂屋全空。圆桌桌高760毫米，椅心半径890毫米，按旋转椅实际投影检查侧／北后方600毫米布置通路；用户已补充确认厨房只做饭、堂屋圆桌吃饭会客。

厨房烟机独立排烟：从烟机顶部上行后穿东墙，沿东外墙X11.80向上至+6.10米，处于露台外侧，不直接朝院子或露台座位排放；暂按180毫米管径示意、设置防倒灌及检修意向。总路长约4.88米，实际烟机静压、管径、出口高度、风向及邻窗条件待产品与现场复核，不能作为已验算的排烟方案。

院墙两侧沿前后屋外墙边线接通，统一墙身、压顶及勒脚，调整相冲的花盆和铺装；不在连接处留下缺口。前屋露台西侧户外桌椅休闲，东侧可收拢晾衣架，中部活动／通行，保留东西连廊连接、栏杆和露台排水；不将娱乐露台封为室内。排烟立管与晾晒区分开，实际抗风固定、荷载、防滑与防水仍需深化。

所有改变同步共用数据、建筑工程、3D、图纸、房间说明、相机和11张室内图，另补两页变更／屋顶排烟图，形成26页K版图册；保留J版PDF与交付包及本地快照。新增两层套卫投影每层约7.41平方米，法定面积、退界及结构仍待现场确认。
