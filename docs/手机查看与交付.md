2026-11-07。基于当前O版及衣柜深化模型。手机包是网页交付物，模型内容不另作简化。

## 检查结果

- Chromium 153手机模拟：320×568、360×800、390×844、430×932及844×390横屏通过。3D加载、分层、房间/室内、56处门窗、亭顶、洗衣、衣柜内部、复位和加载后断网操作无脚本错误。
- 已修复横屏画布原先高620px、超出390px屏幕的问题。现横屏画布高334px，控制区独立滚动；触屏显示“单指旋转、双指缩放/平移”。
- 手机站直接请求GLB，免去Base64模型脚本解析；原电脑页面仍支持内嵌模型。手机3D首次加载约14.6 MiB（服务器压缩及缓存前）。
- 模拟1 MiB/s下载、100ms延迟、4倍CPU减速并禁用缓存：约16.5秒可操作；这是桌面模拟结果，不是某型号手机的测速。
- 缺失模型及不支持WebGL的错误提示已检查；不支持WebGL时仍可从页面导航查看静态图册/效果图。
- **未做真实iPhone Safari、Android设备或微信内置浏览器测试。** 手机GPU、内存及内置浏览器情况不由上述模拟证明。正式发送前用一台真实手机打开已部署链接试用。

## 推荐交付：发网站链接

1. 解压手机包，把**解压后包含index.html的全部内容**上传到你的静态网站空间或现有网站目录，保持model、viewer、精装效果图、renders和drawings的相对位置。
2. 将该目录的HTTPS访问地址发给手机用户，或用这个真实地址生成二维码。无需让手机用户安装Blender、解压工程或单独保存HTML。
3. 接收者在浏览器中打开链接，点“打开交互3D”。首次建议Wi-Fi；竖屏的操作区在模型下方，横屏在左侧。
4. 如果文件预览/聊天内置页面没有运行3D，使用“在浏览器打开”；仍无法运行时可看同一站点的效果图和PDF。

当前只准备了本地站点与ZIP，**尚未上传公网，没有已发布的手机访问网址或二维码**。部署目标可用你现有的静态网站服务器；不需要数据库或后端应用。

## 同一Wi-Fi现场演示

在电脑上只对手机站点目录运行：

```bash
cd '/home/xinchangyang/chance_software/rural-courtyard-house/delivery/手机查看站点-O'
python3 -m http.server 8080 --bind 0.0.0.0
```

手机和电脑连同一个网络，手机浏览器填写：

```text
http://电脑的局域网IP:8080/
```

使用电脑当前连接Wi-Fi网卡的IP；不要填写localhost或127.0.0.1，那会指向手机自身。若电脑有多网卡，选择与手机同一网段的地址。电脑保持开机，结束演示后按Ctrl+C关闭服务器。跨网络接收者使用上面的HTTPS网站方式。
