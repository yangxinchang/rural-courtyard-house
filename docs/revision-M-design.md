# M版：居住动作、收纳与精装效果复核

2026-11-06。用户要求检查当前项目、继续优化房屋布局和装修，并输出与3D一致的效果图。沿用已确认的2.2／1.8米床、纯厨房、堂屋圆桌餐叙、外移套卫、封闭门洞、院墙、前场8米与一层杂物屋；上述建筑外包仍为方案尺寸。

本轮以可复现问题和已有空间利用为重点：

1. 次卧1.8米床向北移200毫米，南侧入门转身通道由630增至830毫米，西侧床尾950毫米保留；北侧敞开通往书桌区，床不越原房间地面。北区西墙增加1350毫米长、550毫米深滑门衣柜，南端Y21.95与床北端留710毫米转弯带；原书桌东移并加宽至1500毫米，椅子与套卫门前路线错开，避免收纳依赖家庭厅。
2. 老人房北私用区安排靠北窗单椅和矮边柜，供穿衣、短时休息；西侧原衣柜和中部通向套卫的路线保留。新增家具不落入套卫开门包络。
3. 二层主卧西衣帽间高柜北端退至Y23.10，北窗前留约1060毫米，消除高柜遮窗。柜深不加大，滑门侧通路保留。
4. 厨房洗碗机上方只做连续台面，移除与机器重叠的实心柜身；灶台与水槽之间保留备餐台。小家电及冰箱工作面沿用，不再加岛台或餐位。
5. 圆桌中心新增木框暖光吊灯，堂屋南段照明沿用；次卧衣柜／书桌补照明、柔和帘片，老人北区增加阅读点与低位导向灯。新中式暖白、木色、浅石、米色织物延续，餐椅和休闲椅补软垫，桌面餐具表达吃饭会客用途。新增灯具电源随共用数据更新，非照度／电气验算。
6. 现有11张室内图仍为K版，未包含L版杂物屋的外部遮挡。本轮全部从M版完整模型重渲，新增老人北区与次卧书桌收纳两张机位，共13张2560×1440；七张外观同步，图册增加本轮复核页，合计28页。

门扇、静态家具与方案人体包络检查用于发现拥堵，不作为法规或实际产品合格结论。所在地、边界、日照、结构、产品型号和机电施工条件未齐全，继续记录为待办，不凭效果图判断已经满足。

检查补充：新衣柜若仍从Y21.75起，会使床尾转弯带不足600mm人体包络；已把柜体起点北移至Y21.95，路径断言先失败后通过。灯光是设计效果补光，并非现场日照／照度模拟。

用户明确允许适当增加房屋使用面积和宅基地，并用箭头更正杂物屋在大门右前方。本轮将杂物屋移至X11.00～14.60、Y-7.40～-3.20，3.60×4.20米、一层及平屋顶沿用；西门朝中部空地，货架随门位改至北／东墙。右侧场地示意面宽由14.60增加至15.20米，杂物屋东侧和南侧均留600mm示意余量，北侧至前屋南墙约3.80米；完整边界(0,-8,15.2,29.4)。主屋目前通过布局调整已取得所述通路和收纳空间，本轮未再扩大主屋轮廓。
