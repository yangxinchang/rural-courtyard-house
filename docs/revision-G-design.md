# G版：居住布局与装修深化

用户要求优化房屋布局，先完成房屋设计，再完成装修，并在3D中体现，列出待办逐项完成。初版日期2026-11-04；2026-11-05续做床A及茶几微调，用户确认坐北朝南、老人目前不需要轮椅或助行器，面宽仍待定。本版沿用已确认的六人居住、三开间前后两栋、前房平屋顶露台、红瓦半层、无树院子、双侧连廊、右后封闭梯、二层最后标记侧门、屋后5米与RC框架意向。未提供的新风格不另作假设，沿用米白、暖灰、木色。下面的细部为设计方安排。

## 装修设计

所有装饰物与家具写入共用数据，图纸与Blender/GLB同时消费。装饰可随查看器家具开关隐藏。

- 卧室：木地板、米白墙、木色床具；前客房靠西床头板，老人房/主卧采用岛式低床头板以保留北侧通路；两张单人床增床下抽屉表现。
- 窗帘：前客房南窗、老人房及主卧南窗、双床房北书桌窗设置两侧帘片，不以窗帘跨过门洞。保留玻璃中央可见。
- 厨餐：浅色石英石台面、耐擦洗背板、吊柜/柜下灯带、六人餐桌上方线形吊灯，餐厨通过地毯以外的材料/灯光区分，厨房操作区不放地毯。
- 厅区：首层起居室及二层家庭厅电视背景板与地毯；家庭厅双人书桌、收纳柜、阅读灯在3D中体现。
- 室内顶面采用米白平顶意向；房间室内视角显示顶面，布局视图隐藏顶面以查看家具。顶面与布灯仅为空间表达，吊顶构造和净高待深化。
- 卫浴：沿用灰绿防滑砖、木色镜柜；老人套卫补扶手及淋浴座凳示意，位置不挡门和主要通行；各洗手台补镜灯，淋浴区补置物层板，避开淋浴升降杆。
- 入户：前通堂原换鞋凳保留，补浅鞋柜；不占中部南北贯通路。灯具高度、表面材质、柜体和扶手均为装修意向，非施工构造或照度验算。
